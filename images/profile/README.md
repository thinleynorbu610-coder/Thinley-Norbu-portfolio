# Profile photo & logo

- `bg.png` — the portrait shown in the hero and About sections. Replace this
  file with your own photo (keep the filename, or update the image `src`
  values in [index.html](../../index.html) if you rename it).
- `crest.png` — an alternate profile image retained in the folder.
- `logo.png` — the supplied blue gradient "TN" mark used in the navigation,
  footer, and browser tab. It has a transparent background.
